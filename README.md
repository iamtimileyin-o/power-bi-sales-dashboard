# 📊 Retail Sales Analysis Dashboard

## Project Overview

This project uses Microsoft Power BI to analyze retail sales performance and generate actionable business insights. The dashboard explores sales performance, regional trends, product categories, sales representatives, and customer feedback.

## Objectives

* Analyze overall sales performance.
* Identify top performing sales representatives.
* Evaluate sales performance across regions.
* Identify product categories generating the most revenue.
* Understand customer feedback and satisfaction.

## Key Business Insights

* Total sales generated: $2.1 million.
* Chioma was the top performing sales representative.
* Port Harcourt generated the highest sales across all regions.
* Electronics generated the most revenue.
* Customer feedback was generally positive.

## Recommendations

1. Reward and learn from top performing sales representatives.
2. Maintain adequate stock of best-selling products.
3. Focus marketing efforts on high-performing regions and product categories.
4. Improve service based on negative customer feedback.
5. Offer multiple payment options to improve customer convenience.

## Tools Used

* Microsoft Power BI
